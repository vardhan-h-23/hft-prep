5.3 Synchronizing operations and enforcing ordering
The required enforced ordering comes from the operations on the std::
atomic<bool> variable, data_ready;, they provide the necessary ordering by virtue of
the memory model relations happens-before and synchronizes-with.

5.3.1 The synchronizes-with relationship
Basic idea is suitably-tagged w operation is sync with suitably-tagged r in some other thread 
that reads either value written by w or subsequent w in same thread, 
or subsequent read-modify-write on x by any thread

5.3.2 The happens-before relationship
If one operation A on a thread is happened before operation B on another thread,
then A happens before B 
if operation A in one thread synchronizes with operation B in another thread, 
then A inter-thread happens before B.
It’s also a transitive relation: if A inter-thread happens before B and B interthread 
happens before C, then A inter-thread happens before C.

"These two together mean that if you make a series of changes to data in a single thread, you need
only one synchronizes-with relationship for the data to be visible to subsequent operations 
on the thread that executed C."

5.3.4 Release sequences and synchronizes-with:
summary:
if we have chain of operations starting from store(with release type...) and ending with load (with acquire)
and let's say if we have a sequence of rmw operations in the middle we can get a synchronizes-with relationship
Any atomic rmw operations in the chain can have any memory ordering

Deep explanatory:
If store tagged with memory_order_release, memory_order_acq_rel, or memory_order_seq_cst
load tagged with memory_order_consume, memory_order_acquire, or memory_order_seq_cst,
each operation in the chain loads the value written by the previous operation,
then chain of operations constitutes a release sequence and the initial store synchronizes
with (for memory_order_acquire or memory_order_seq_cst) the final load.

Any atomic read-modify-write operations in the chain can have any memory ordering
(even memory_order_relaxed)
